Code examples and hands-on projects covering Amazon Bedrock, Retrieval-Augmented Generation (RAG), AI Agents, and Generative AI.

# Creating virtualenv (venv)

Checking Python version
 
>> python --version
>
>> Python 3.12.0

Creating the .venv file

> python -m venv .venv

Activating on Windows
> .\.venv\Scripts\Activate.ps1

Activating on Linux/macOS
> source .venv/bin/activate
